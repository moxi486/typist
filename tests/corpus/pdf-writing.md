# 一份适合分享的文档

使用文件菜单中的「导出 PDF」，在保存前检查纸张、方向、页边距和分页。试着将方向改成横向，再缩小或放大页边距。

## 清楚地表达

正文保留 **重点**、*语气* 与 `代码`，中文和 English 可以混排。应用的深色主题不会改变导出页面的白色背景。

> 预览与导出使用同一份当前编辑内容。

- 设置 A4 或 Letter
- 在页眉使用 `{title}`
- 在页脚使用 `Page #`
- 翻页检查长表格

## 可阅读的代码

```cpp
const auto document = currentMarkdown();
exportPdf(document);
```

## 检查表格

| 检查项 | 结果 |
| :--- | :---: |
| 标题与正文 | 清晰 |
| 长段落自动换行 | 保留文字 |
| 中文与英文 | 同时显示 |
| 代码块 | 保留缩进 |
| 行内公式 $E=mc^2$ | 离线渲染 |
| 页眉页脚 | 独立留白 |
| 不同纸张方向 | 可预览 |
| 四边页边距 | 统一设置 |
| 空白页眉 | 隐藏 |
| 空白页脚 | 隐藏 |
| 取消导出 | 不写入 |
| 未应用的段落草稿 | 纳入快照 |
| 成功导出 | 记住偏好 |
| 失败导出 | 保留已有文件 |
| 结束检查 | 保存并分享 |
