# A quieter place to write

从想法到代码，保持写作的节奏。Choose a language above, copy a complete block, and keep writing below.

## Code that feels natural

```cpp
#include <string>

std::string greet(const std::string& name) {
    if (name.empty()) {
        return "Hello, world!";
    }
    return "你好，" + name;
}
```

Enter follows the current indentation. Tab and Shift+Tab indent selected lines together. Ctrl+Enter returns to prose.

```python
def writing_session(minutes):
    for minute in range(minutes):
        print("One thought at a time.")
```
