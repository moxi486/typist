# Literal spreadsheet cells

| Name | Value | Note |
| :--- | ---: | --- |
| \*\*stars\*\* | \$x^2\$ | line one<br>line two |
| \<em\>plain\</em\> | A\|B | path\\one |
| \`code\` | \[label\]\(target\) | quoted "value" |
| real<br>break | \<br\> stays literal | \&lt; is text |

Tail stays outside the table.
