# PDF 页面设置与预览

通过 **文件 → 导出 PDF**（`Ctrl+Shift+P`）打开设置窗口。左侧可设置纸张、方向、页边距、页眉页脚、跨页表头和章节分页。右侧可逐页检查，预览与导出使用同一套分页和绘制逻辑。

- 纸张可选 A4、Letter、A3、A5、Legal 或自定义。自定义宽、高各为 50–1000 mm，横向会交换宽和高。
- 页边距可设为 5–60 mm，四边使用同一值。纸张尺寸、页边距及页眉页脚必须给正文留出空间，调整后可在预览中检查。
- 页眉或页脚留空时隐藏对应区域。`${title}` 插入标题，`${author}` 插入作者，`${pageNo}` 插入当前页码，`${pageCount}` 或 `${totalPages}` 插入总页数。`{title}` 和 `#` 也可继续使用。默认页眉为标题，页脚为 `Page #`。 [Typora 页眉页脚变量](https://support.typora.io/Export/#header--footer)
- 跨页重复表头：控制长表格后续页面是否重复第一行。
- **一级标题之间分页**默认关闭。开启后，从第二个一级标题起，每个一级标题单独起页。首个一级标题和它之前的引言自然排版。脚注区从新页开始，同一组脚注连续排版。二级及更低级标题沿用自动分页。[Typora PDF 分页参考](https://support.typora.io/Export/#page-break)

## 文档属性

在导出窗口的「文档属性」页填写标题、作者、创建者、主题和关键词。留空时，标题使用文档名，创建者使用 Typist。属性写入 PDF 的 XMP 元数据，可在支持 XMP 的阅读器中查看。普通导出可为当前文档重新填写，重复导出和覆盖导出沿用上次成功时填写的属性。 [Typora PDF 元数据说明](https://support.typora.io/Export/#pdf-metadata)

## 文件和日期变量

| 变量 | 页眉页脚中的内容 |
| --- | --- |
| `${currentPath}` | Markdown 文件的完整路径 |
| `${currentFileName}` / `${currentFileFullName}` | Markdown 文件名，分别省略和包含扩展名 |
| `${currentFolder}` | Markdown 文件所在文件夹的完整路径 |
| `${outputPath}` | 实际导出的 PDF 完整路径 |
| `${outputFileName}` / `${outputFileFullName}` | PDF 文件名，分别省略和包含扩展名 |
| `${today}` | 本地日期，格式为 `YYYY-MM-DD` |

未命名文档的源文件变量展开为空。输出路径在保存时确定，预览中会保留输出变量的原文。重复导出时，文件变量按本次实际路径展开，覆盖导出使用最终目标路径。 [Typora 导出变量说明](https://support.typora.io/Export/#variables)

## 手动分页

选择 **段落 → 插入分页符**，让当前位置之后的内容从新页开始。渲染视图显示一条标有「分页符」的虚线。可以选中它删除，也可以撤销插入。源码中用上下各一个空行隔开的 `<div style="page-break-after:always"></div>` 表示。也支持同一个空 `div` 中的 `break-after: page`，两种声明可同时使用。[Typora 手动分页参考](https://support.typora.io/Page-Breaks/#html-and-inline-css)

PDF 预览和导出始终应用手动分页。连续分页符及同一位置的手动和一级标题分页会合为一次。文档开头或结尾的分页符不会生成空白页。DOCX 将手动分页符写成 Word 原生分页，HTML 保留打印分页样式。

## 保存与验证

点击“导出”后选择位置，未填写扩展名时补齐 `.pdf`。成功写入后才记住页面设置和页眉页脚模板。过长的页眉页脚在边界内省略显示，避免挤入正文。输出始终采用适合打印的浅色页面，应用深色主题不改变 PDF 的纸张颜色。

导出读取当前编辑内容，包含源码视图和未应用的段落 Markdown 草稿，不修改编辑文档与撤销历史。预览使用分离的排版副本，修改选项不会触碰原文件。输出采用临时文件提交，失败时保留已有目标 PDF。

预览按 96 DPI 绘制并缩放适配窗口，PDF 中的文字仍按原生矢量文字输出，公式和图表沿用原有图片渲染。每次设置变化后重新分页，超长文档可能需要短暂等待；翻页仅绘制所选页面，不将整份文档的每页同时缓存为图片。PDF 暂不提供交互链接注释、书签、打印机选择、页码范围或非等宽四边距。

安装包示例 `share/typist/examples/pdf-writing.md` 可用于检查章节、脚注、代码块和表格。`pdf_page_setup` 验证纸张尺寸、方向、页码模板、预览 / 导出页数，以及失败时保留文件。窗口回归覆盖自定义尺寸校验、设置记忆、取消、保存后缀和草稿快照。`--bench-pdf` 可在部署后的应用中进行临时导出检查。
