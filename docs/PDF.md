# PDF 页面设置与预览

通过 **文件 → 导出 PDF**（`Ctrl+Shift+P`）打开设置窗口。左侧设置纸张、方向、页边距、页眉页脚及跨页表头；右侧预览当前页，并可翻页检查。预览采用与导出相同的原生分页和绘制逻辑，不依赖外部 PDF 阅读器或联网服务。

- 纸张：A4 或 Letter；方向：纵向或横向。
- 页边距：四边统一设置，范围 5–60 mm。
- 页眉 / 页脚：留空隐藏对应区域；`{title}` 插入当前 Markdown 文档名称，`#` 插入当前页码。默认页眉为文档名，页脚为 `Page #`。
- 跨页重复表头：控制长表格后续页面是否重复第一行。

点击“导出”后选择位置，未填写扩展名时补齐 `.pdf`。成功写入后才记住设置；取消设置窗口、取消保存或写入失败不会改变偏好。记住的是页眉页脚模板，文档名称随当前文件变化。过长的页眉页脚在边界内省略显示，避免挤入正文。输出始终采用适合打印的浅色页面，应用深色主题不改变 PDF 的纸张颜色。

导出读取当前编辑内容，包含源码视图和未应用的段落 Markdown 草稿，不修改编辑文档与撤销历史。预览使用分离的排版副本，修改选项不会触碰原文件。输出采用临时文件提交，失败时保留已有目标 PDF。

预览按 96 DPI 绘制并缩放适配窗口，PDF 中的文字仍按原生矢量文字输出，公式和图表沿用原有图片渲染。每次设置变化后重新分页，超长文档可能需要短暂等待；翻页仅绘制所选页面，不将整份文档的每页同时缓存为图片。PDF 暂不提供交互链接注释、书签、打印机选择、页码范围或非等宽四边距。

安装包示例 `share/typist/examples/pdf-writing.md` 可用于检查标题、代码块和表格。`pdf_page_setup` 验证四种纸张方向的预览 / 导出页数、文档不变和失败保留文件；窗口回归覆盖翻页、双语主题、设置记忆、取消、保存后缀与草稿快照。`--bench-pdf` 可在部署后的应用中进行临时导出检查。
