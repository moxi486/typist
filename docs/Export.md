# 通用导出设置

「设置 → 导出设置」适用于 HTML（含无样式）、PNG、PDF、DOCX 和 EPUB。可在每次导出的保存对话框里另选路径。

- **使用文档所在文件夹**是默认选项。未命名文档以用户主目录为起点。
- **使用上次导出的文件夹**记住最近一次成功导出的实际目录，可跨格式使用。
- **选择自定义导出文件夹…**保存一个固定目录。取消选择会保留原设置。如果自定义或上次导出的目录已不可用，则使用文档所在文件夹，未命名文档使用用户主目录。

开启**导出后打开文件夹**，成功写入文件后会用系统文件管理器打开该文件的所在目录。该选项默认关闭。取消或导出失败时保留上次成功目录。 [Typora 导出设置参考](https://support.typora.io/Export/#export-location)

在「设置 → 导出设置 → 导出后打开文件」中，可按格式开启自动打开。各项默认关闭。普通导出、按上次设置导出和覆盖导出成功后，都会按当前设置用系统默认应用打开相应文件。自动打开适用于扩展名与所选格式匹配的文件。可同时开启「导出后打开文件夹」。 [Typora 导出后选项参考](https://support.typora.io/Export/#configure-after-export-options)

## 按上次设置导出

当前窗口成功导出过当前文档后，可从「文件 → 按上次设置导出」直接进入保存对话框。使用最新文档内容与上次的格式和选项，例如 PDF 纸张、PNG 宽度、HTML 大纲以及 EPUB 书名和封面。PNG 如果选用了「当前主题」，重复导出也会跟随当前主题。

每次仍可另选保存位置，默认目录按通用导出设置确定。取消或失败会保留上次成功设置。新建或切换文档会重置该命令，打开新窗口后从该窗口的首次成功导出开始记录。 [Typora 重复导出参考](https://support.typora.io/Export/#export-with-previous-settings)

「文件 → 按上次设置覆盖导出」会用当前内容直接更新该文档最后一次成功导出的文件，省去选项和保存对话框。文件已移走、已被外部修改或无法访问时，可用「按上次设置导出」另选路径。覆盖失败会保留已有的输出文件。

## HTML 导出主题

在「设置 → 导出设置 → HTML 导出主题」可为有样式的 HTML 选择浅色、深色或跟随编辑器主题。默认跟随编辑器。所选主题用于页面、代码高亮、公式和图表。重复导出和覆盖导出会沿用上次成功的主题。 [Typora HTML 导出主题说明](https://support.typora.io/Export/#change-theme)

## 附加 HTML 内容

在「设置 → 导出设置 → 附加 HTML 内容…」填写并保存 HTML 片段。有样式和无样式的 HTML 导出都会使用这些设置。头部片段放在内置样式之后、`</head>` 之前，可加入自己的 CSS。正文片段放在导出的 Markdown 内容之后、`</body>` 之前，可加入页脚。留空并保存即可清除对应片段。

两种重复导出命令会沿用上次成功时的片段。更改设置后，使用「导出 HTML」或「导出 HTML（无样式）」开始一次新的导出。 [Typora 附加 HTML 内容参考](https://support.typora.io/Export/#add-custom-contents)
