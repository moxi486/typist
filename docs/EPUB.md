# EPUB 电子书导出

通过 **文件 → 导出 EPUB**（File → Export EPUB）填写书名、作者和书籍语言，可选封面与章节拆分，再选择保存位置。作者可留空；语言使用 `zh-CN`、`en` 等标签。作者、语言和章节拆分选项在成功导出后记住，书名默认使用当前文件名。

封面可通过“浏览…”选择本地 PNG/JPEG/WebP/BMP 图片，窗口提供等比缩略图，可随时清除。封面会嵌入 EPUB，并声明为阅读器可识别的封面图片，同时作为第一张阅读页面；原图片保持不变。封面与正文使用同一图片时去重打包，尺寸超过 1600×1600 会等比缩小。无效或缺失封面会阻止导出并保留已有目标。封面路径不跨次记忆，以免新文档误用上一本书的封面。

勾选“按一级标题拆分章节”后，每个正文 `# 标题` 开始一个新的 XHTML 章节。第一个一级标题前若有序言或 `[TOC]`，会单独保留在最前；没有一级标题时保持一个正文文件。二至六级标题、引用块里的标题不会触发拆分。阅读顺序由书籍目录和 spine 定义，重复标题、正文目录及内部链接会指向正确章节。脚注集中在最后一个章节，引用和首个引用的返回链接支持跨章节跳转。最多支持 1000 个一级标题；此功能拆分当前文档，不合并多个 Markdown 文件。

输出是原生生成的 EPUB 3 文件，无需 Pandoc、Java、网络服务或额外运行时。正文随阅读器字号与屏幕宽度重排，分页由阅读器决定。阅读器目录来自正文顶层标题，重复标题具有独立目标；正文 `[TOC]` 和标题链接同样可跳转。引用块中的标题保留外观，不加入书籍目录。

支持正文、粗斜体、删除线、代码与语法着色、列表及任务状态、引用、表格、分隔线、脚注与返回链接。本地图片按 Markdown 所在目录查找，自动旋转后等比缩小到 1600×1600 以内并去重嵌入 PNG；公式和支持的 Mermaid 图表也作为图片嵌入。原文件不受影响。复杂公式与图表的支持范围见 [Advanced-Markdown.md](Advanced-Markdown.md)。

HTTP(S) 和邮件链接保留；相对文件链接、找不到的标题链接与其他协议保留显示文字。远程图片不会下载，缺失图片保留替代文字；不支持的图表或公式保留源码。导出完成后可展开提示查看这些内容。未命名文档的相对图片没有可确定的目录，请先保存文档。原始 HTML 块会使本次导出失败；行内 HTML 除 `<br>` 外按字面文字显示。列表仍遵循当前 Markdown 模型的限制（不保留自定义起始编号和复杂的多块列表项）。

导出包含尚未应用的段落 Markdown 草稿和源码视图的当前内容，不会修改编辑器内容或撤销记录。写入采用临时文件提交，解析或写入失败时保留已有目标文件。单次 Markdown 源码上限 16 MiB，嵌入 PNG 合计上限 128 MiB、最多 10,000 张。

取消章节拆分时仍输出一个正文文件，可独立选择是否使用封面。目前不含多文件章节合并、固定版式、字体嵌入或 DRM；封面显示与实际分页由阅读器决定。示例见安装包 `share/typist/examples/epub-writing.md` 与 `epub-chapters.md`。开发者可用 `--bench-epub` 检查单正文导出，用 `--bench-epub-chapters` 检查章节拆分；环境变量 `TYPIST_EPUB_COVER` 可传入本地封面路径。格式回归在 `epub_export`，窗口和草稿回归在 `window_regressions`。标准校验使用 [W3C EPUBCheck](https://www.w3.org/publishing/epubcheck/)，验证工具不随应用打包。
