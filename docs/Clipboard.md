# 剪贴板复制格式

选中文档内容后，在「编辑」菜单选择复制格式，也可在编辑器右键打开「复制为」子菜单。

- 「复制为 Markdown」将选区作为 Markdown 文本复制，快捷键为 `Ctrl+Shift+C`。
- 「复制为纯文本」复制显示文字。源码视图和段落源码草稿会复制所选源码。表格矩形选区以制表符分隔单元格。
- 「复制为 HTML 源码」将选区转换为 HTML 片段并作为纯文本复制，可粘贴到代码编辑器。
- 「复制无主题样式」同时提供 HTML 和纯文本。支持富文本的应用可以粘贴标题、强调、链接和表格等结构，并使用目标应用自己的字体和颜色。

两种 HTML 格式均支持渲染视图、源码视图和段落源码草稿中的选区。它们使用选区中的 Markdown 生成片段，保留表格内换行与成对的无属性下划线标签，相对链接和图片引用沿用原路径。其他原始 HTML 作为文字显示，公式和图表使用源码表示。复制整篇内容及其主题排版可使用「文件 → 导出 HTML」。

从网页复制后粘贴为 Markdown 的操作见 [HTML 导入与网页粘贴](Import.md)。复制格式参考 [Typora 复制粘贴文档](https://support.typora.io/Copy-and-Paste/)。

## 复制和剪切整行

在「设置 → 复制和剪切整行」启用后，可在源码视图、段落源码编辑框或渲染视图的代码块中，通过「编辑」菜单或复制、剪切快捷键操作光标所在行。自动折行的文字仍算一行。已有选区时按选区操作。

代码块中的整行复制包含行尾换行。剪切时保留围栏，且可一步撤销。源码最后一行没有换行符时，复制也保留这个格式。设置默认关闭，并在下次启动时保留。 [Typora 编辑功能说明](https://support.typora.io/What's-New-1.1/#editing)
