# 代码高亮与段落 Markdown 编辑

代码块按围栏中的语言标识着色。在「段落 → 代码语言」修改当前整个代码块的语言；修改可一次撤销。留空或使用未知语言时显示普通代码。「设置 → 语法高亮」可开关编辑器中的着色。

常用标识包括 cpp / c++、c、python / py、javascript / js、typescript / ts、json、bash / sh、powershell / ps1、java、cs / csharp、go、rust、swift、kotlin、sql、html / xml、css、yaml / yml、toml、markdown / md、latex / tex。此高亮器使用轻量词法规则，不等同于 IDE 的语义分析。支持常见多行注释、Python 三引号字符串和 C++ 原始字符串；超过 32768 字符的单行跳过高亮，保留全部原文。

源码模式也会高亮 Markdown 标记和标准代码围栏。颜色随浅色、深色主题切换；着色不修改文档文字、Markdown 格式或撤销历史。HTML、PDF、DOCX 的代码块使用同一套浅色打印配色；深色 HTML 使用相应主题配色。导出内容仍是可选择的代码文字。

将光标放入正文段落或标题，按 `Ctrl+Enter`，或选择「编辑 → 编辑段落 Markdown」，打开就地源码框。它显示该段的 Markdown，包括已有的粗体、斜体、删除线、链接、行内代码和公式。编辑完成后按 `Ctrl+Enter` 或「应用」重新渲染；按 `Esc` 或「取消」放弃当前尚未应用的输入。点击文档其他位置也会应用。

整段应用支持嵌套格式，也可将段落改成标题、列表等 Markdown 结构。一次应用对应一个文档撤销步骤。源码框内的撤销和重做操作针对正在输入的源码。打开源码框、切换主题或读取草稿快照不会增加文档撤销步骤。

手动保存、自动保存、导出与崩溃草稿会包含源码框中的最新输入，同时保持编辑框打开。保存后再取消编辑会恢复应用前的段落，并将这个恢复标记为待保存的修改。切换文件、关闭或切换到完整源码视图时沿用已有的保存保护。此模式目前适用于正文和标题；列表、引用、表格、代码块及独立公式 / 图表使用各自已有的编辑方式。随光标自动揭示整段原始标记仍未实现。

## 代码块写作

光标进入代码块时，编辑区顶部显示语言、复制代码和退出代码块工具条。它使用正文上方的留白，不遮挡代码，也不修改文档排版。语言可从列表选择，或输入自定义标识后按 Enter；按 Esc 放弃尚未提交的语言名。选择「纯文本」移除语言标签。修改语言是一次可撤销操作。工具条随界面语言和主题切换，完整源码视图中隐藏。

「复制代码」复制当前整个代码块的原文，包括空行、缩进和末尾换行，不包含 Markdown 围栏；「复制为 Markdown」仍按选区保留 Markdown 标记。普通粘贴、纯文本粘贴和「粘贴为 Markdown」在代码块里都保留文字原样，不将 `#`、`**` 或列表转换成富文本。

代码内容本身含有三个或更多反引号时，保存会自动选择更长的外围围栏；语言信息里含有反引号时使用波浪线围栏。因此可以把带代码围栏的 Markdown 示例作为代码保存，重新打开及源码切换后仍保留原文。

- `Enter` 继承行首的空格或 Tab；开括号后增加一层缩进，Python 冒号后同样增加缩进。成对括号中间 Enter 分出内层与闭括号两行。注释和多行字符串中的括号不会触发额外缩进。
- `Tab` 插入空格至下一个四列制表位；选中多行后同时缩进。`Shift+Tab` 删除行首最多四个空格或一个 Tab，保留反向选区；整次修改可一步撤销。
- 在行首缩进中按 `Backspace` 退回上一制表位；`Home` 在行首与首个非空白字符之间切换，`Shift+Home` 可选取。
- 设置中的「自动配对括号与引号」也适用于代码块；选中文字后输入开括号或引号可包裹选区。
- `Ctrl+Enter` 或「退出代码块」跳到后面的普通段落；如果后面没有正文则创建新段落。它保留代码中的所有尾部空行。代码块最后一个空白行再次 Enter 也可退出，`Shift+Enter` 保留空白代码行；中间的空行不会拆开代码块。

这些规则用于常见代码片段，不代替 IDE 的语言语义分析。缩进和代码工具条目前用于渲染视图中的代码块。

## 选择与定位

「编辑 → 选择范围」提供四种选择命令：

- `Ctrl+D` 选择光标处的单词。
- `Ctrl+L` 在正文按 Unicode 句子边界选择。代码块和源码按实际换行选择当前行，表格中选择光标所在整行。
- `Ctrl+E` 选择相同格式组合的连续文字，例如粗体短语或链接。在表格中选择整个单元格。无对应样式的普通文字和源码按单词选择。
- 「选择段落／块」选择当前段落、整个代码块或整张表。源码中选择当前行。

「视图 → 跳转」可定位显示行的首尾或文档首尾。`Ctrl+J` 将当前光标或选区活动端滚动到可见位置，保留选区方向。段落源码框打开时，这些命令操作当前草稿。选择和跳转不会写入文档或增加撤销步骤。

快捷键参考 [Typora 快捷键](https://support.typora.io/Shortcut-Keys/)。

## 删除范围

「编辑 → 删除范围」提供删除单词、行或句子、样式范围、段落或块。已有文本选区时，命令直接删除所选文字。光标没有选区时，按对应范围删除。

- `Ctrl+Shift+Backspace` 删除正文当前句子并收拢相邻空格。代码和源码按实际换行删除。删掉代码块最后一行文字会保留带语言标识的空代码块，可再次删除这个空块。
- 删除段落或块可删除整个代码块、当前列表项及其子列表。代码块也可按整个样式范围删除。表格内的光标可以删除整表。
- 表格中的「删除行／句子」删除当前行或矩形选区涉及的行，保留表头和至少一行正文。「删除样式范围」可清空当前单元格，其他删除命令应用到矩形选区时清空所选单元格。

每次删除可一步撤销。在段落源码框中删除时使用草稿自己的撤销记录。操作参考 [Typora 删除范围](https://support.typora.io/Delete-Range/)。

## 调整标题级别

在渲染视图选择「段落 → 提升标题级别」或按 `Ctrl+=`，三级标题会变成二级标题。「降低标题级别」或 `Ctrl+-` 将三级标题变成四级标题。macOS 使用 `Cmd`。一级和六级标题分别停在各自的边界。

光标位于标题内时调整该标题。选中多个段落时，仅调整选区覆盖的标题，保留正文、行内样式和选区方向。整次调整可一步撤销，大纲会随之更新。在完整源码视图和段落源码框内，可以直接编辑 `#` 标记。

## 下划线

选中文字后按 `Ctrl+U`（macOS 为 `Cmd+U`），或选择「格式 → 下划线」。如果整段选区的文字都已加下划线，再按一次会移除该格式。光标没有选区时，命令切换随后输入文字的下划线。渲染视图中输入成对的 `<u>…</u>` 也可就地渲染。

Markdown 使用无属性的 `<u>` 与 `</u>` 保存下划线，可与粗体、斜体和链接组合。普通链接自身的下划线与此格式独立。完整源码视图和段落源码框可用同一快捷键包裹或解开单行选区。HTML、PDF、DOCX、EPUB 及无主题复制都保留正文的下划线。[Typora Markdown 参考](https://support.typora.io/Markdown-Reference/#underlines)
