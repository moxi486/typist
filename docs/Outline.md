# 大纲导航

从「视图 → 大纲」或 `Ctrl+Shift+T`（也可用 `Ctrl+Shift+1`）打开侧栏。大纲列出渲染视图中的标题，点击标题或选中后按 `Enter` 即可跳转。源码视图会提示切回渲染视图。

大纲右上角的 `⋯` 与右键菜单提供「平铺大纲」和「可折叠大纲」。平铺大纲按标题级别缩进，可折叠大纲把标题放在最近的上级标题下。点击箭头或使用 `←` / `→` 折叠与展开。默认平铺，视图偏好会保存到下一次启动。

在筛选框输入标题中的关键词。匹配不区分大小写，树形视图会同时显示匹配标题的上级标题，便于判断章节位置。按 `Enter` 跳到首个匹配，或按 `↓` 移入结果，再用方向键选择。清除筛选后恢复原来的折叠状态。

编辑时大纲加粗光标所在章节的标题，滚动时标记视口顶部所在章节。如果当前标题在折叠分组中，大纲标记仍可见的上级标题。「定位当前标题」会展开路径并滚动大纲，必要时清除筛选，文档光标停在原位。切换文档时重置筛选与折叠状态。

行为参考 [Typora 大纲文档](https://support.typora.io/Outline/)。

## 导出到 HTML

在「设置 → HTML 导出包含大纲」启用目录导航。此选项默认关闭，适用于「文件 → 导出 HTML」和「文件 → 导出 HTML（无样式）」。导出时沿用侧栏的平铺或可折叠模式。点击大纲标题跳转到正文，正文中的 `[TOC]` 也会保留。

带主题的 HTML 在宽窗口显示侧栏，在窄窗口将大纲放到正文上方，打印时隐藏侧栏。无样式导出保留标题、链接、嵌入图片与可折叠导航，省略主题 CSS 和应用生成的代码着色。文档自带的 HTML 样式会保留。 [Typora HTML 导出文档](https://support.typora.io/Export/#html)
