# 表格写作与电子表格粘贴

光标进入表格时，编辑区顶部显示表格工具条。它提供行列增删、列对齐、整表复制和退出操作，适配浅色 / 深色主题与中英文界面。尺寸显示包含表头。表头不能作为数据行删除，表格至少保留一行表头和一行数据、一列。

选择多列再对齐时，会设置这些列的全部单元格；新增行沿用列对齐。新增列的表头使用表头样式，正文保留已有的粗体、斜体、链接等内容。增删、对齐和批量粘贴均可一步撤销。

## 从 Excel 等应用粘贴

复制包含 Tab 分列的文字后，可直接在编辑区粘贴。在正文里会创建表格，首行作为表头；只有一行数据时补一行空白数据行。在现有表格里，从当前单元格或选区左上角填入，需要时向下、向右扩展。没有覆盖的单元格与表格外的正文保留。支持制表符、CRLF / LF 换行、双引号单元格、双引号内换行以及用两个双引号表示一个引号。

数据作为字面文字插入：`**stars**`、`$x$`、`<br>` 等不会自动变成格式或公式。真实单元格换行保存为 Markdown 的 `<br>`，重新打开会恢复换行；字面文字 `<br>` 使用转义保留。HTML、PDF、DOCX 同样区分字面文字与真实换行。

选中矩形单元格后粘贴一段单值文字，会填充整个选区。按 Delete / Backspace 清空选中单元格；剪切先复制内容再清空，保留表格结构。普通单元格内的文字选区仍可正常编辑。

表格操作支持至多 500 行、40 列，一次网格粘贴最多 2 MiB。超限或引号未闭合的数据会提示错误并保留文档。源码视图、段落 Markdown 编辑框与代码块保留普通文字粘贴行为。「粘贴为纯文本」可跳过网格识别。

## 复制与导航

- 选中多个单元格后 Ctrl+C / Ctrl+X，输出适合电子表格的 TSV。包含制表符、换行或引号的单元格使用双引号包装。
- 工具条或「表格」菜单的「复制表格为 Markdown」复制当前整张表，保留列对齐和行内格式；「复制表格用于电子表格」复制整表 TSV。
- Tab / Shift+Tab 前往下一格 / 上一格。末行最后一格 Tab 添加一行；第一格 Shift+Tab 回到表格前。
- Ctrl+Enter 或「退出表格」移到表格后可继续写作的普通段落；原有正文与标题保留。

此功能处理 Tab 分列的剪贴板文字，不读取 XLSX 工作簿或计算电子表格公式。Markdown 表格不支持合并单元格；请使用普通矩形表格。
