# 快速打开

按 `Ctrl+P`，或选择「文件 → 快速打开」，输入文件名或相对路径的一部分。支持大小写不敏感的模糊匹配、中文以及以空格分开的多个关键词，例如 `docs 计划`。文件名匹配优先，最近文件在相同匹配程度下优先。

窗口会显示文件名和所在路径，帮助区分重名文件。`↑` / `↓` 选择，`Page Up` / `Page Down` 每次移动五项，`Enter` 打开，`Esc` 关闭；也可双击结果。没有结果时 Enter 不会打开其他文件。输入和选择均不修改当前文档。

搜索范围是文件侧栏当前的工作区；尚未打开工作区时，使用当前文档所在目录，没有文档时使用启动目录。最近打开且仍存在的文件也会列出，即使它们位于工作区外。打开工作区内部的子目录文件后，文件侧栏保留整个工作区。

目录在后台扫描，最近文件可以立即打开。扫描只读取文件路径，不读取文件内容，忽略隐藏文件和目录、`build`、`node_modules`，不跟随符号链接。支持 `.md` 扩展名（不区分大小写）。每次打开重新扫描，最多收集 10,000 个 Markdown 文件或访问 100,000 个目录项；达到上限时窗口提示改用更小的文件夹。匹配结果最多显示 100 项，可以继续输入缩小范围。关闭窗口会取消本轮扫描。

确认打开后沿用正常文件打开流程：未保存文档和段落源码草稿支持保存、放弃和取消；取消会保留草稿、当前文档和撤销记录。扫描期间被移动或删除的文件由打开流程报错，当前文档继续保留。界面随应用设置使用中文或英文，并支持浅色和深色主题。

此功能是按文件名和路径查找；文档内容检索继续使用 `Ctrl+Shift+F`。文件夹固定、命令面板和跨工作区内容索引尚未实现。行为参考 [Typora 文件管理文档](https://support.typora.io/File-Management/#open-quickly)。

验证：`quick_open` 覆盖排序、中文、路径、多关键词、去重、目录过滤、大小写扩展名、扫描上限、取消、空结果和键盘操作；`window_regressions` 覆盖未保存草稿保护、工作区保留、中英文和主题。
