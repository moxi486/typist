# 工作区全文搜索

按 `Ctrl+Shift+F`，或选择「编辑 → 在文件夹中搜索」，打开侧栏的「搜索」页。输入关键词后会在停止输入约 300ms 后搜索，也可按 `Enter` 或「搜索」立即开始。支持中文和其他 Unicode 文本，勾选「区分大小写」可以收紧匹配。

搜索范围使用文件侧栏当前的工作区。没有工作区时，使用当前文档目录；没有文档时，使用启动目录。范围显示在输入框上方，悬停可看到完整路径。选择「文件 → 打开文件夹」可更换范围，切换工作区会清除旧结果。

结果按文件分组，组名显示相对路径，以区分不同目录的重名文件。每条结果显示 Markdown 源码行号及匹配位置附近的预览；一行多次匹配只列一次。`↓` 从搜索框进入结果，使用方向键选择，`Enter` 或双击打开该源码行并选择首个命中。定位会切换到源码视图，`Ctrl+/` 可返回渲染视图。

搜索使用磁盘上已保存的 Markdown，不会自动保存或替换当前编辑。打开结果时沿用保存 / 放弃 / 取消流程；取消保留当前文档、段落源码草稿和撤销记录。搜索页打开期间不会因焦点移入搜索框而自动应用段落草稿，仍可使用草稿自己的「应用」或「取消」。

结果生成后，文件可能已被修改或删除。打开时会校验命中行是否仍然相同；变化时提示重新搜索，避免按旧位置选择无关内容。被删除或无法打开的文件会报错，并保留当前编辑内容。

搜索在后台执行。修改关键词或大小写选项会取消旧任务，旧结果不会覆盖新结果；「取消」保留当前轮已找到的部分结果。`Esc` 停止搜索，清空输入会清除结果。切换到其他侧栏页、隐藏侧栏或关闭窗口会取消当前任务；再次打开搜索后可按「搜索」重跑。

范围与上限：

- 只读取 `.md` / `.MD` 文件，按 UTF-8 解码；跳过隐藏条目、`build`、`node_modules` 及符号链接。
- 默认最多显示 200 行匹配，扫描 10,000 个 Markdown 文件或 100,000 个目录项，累计读取 64 MiB。
- 单个文件上限 4 MiB，跳过包含 NUL 字节的二进制内容及无法读取的文件；界面显示跳过数量。
- 达到结果或扫描上限会明确提示缩小关键词或工作区。当前顺序取决于文件系统遍历，不保证先扫描字母顺序最前的文件。
- 输入上限 512 个字符；本批为单行字面文本搜索。正则、多文件替换、文件名筛选和未保存缓冲区全文索引尚未实现。文档内正则搜索 / 替换仍使用 `Ctrl+F` / `Ctrl+H`；按文件名查找使用 [快速打开](Quick-Open.md)。

`workspace_search` 测试覆盖中文、大小写、CRLF、长行预览、递归剪枝、扫描上限、取消、连续重搜、分组和键盘操作；窗口回归覆盖工作区范围、草稿保护、源码定位、过期 / 删除结果、中英文和浅深主题。功能参考 [Typora 全局搜索](https://support.typora.io/File-Management/#global-search)。
