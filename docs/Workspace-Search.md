# 工作区全文搜索

按 `Ctrl+Shift+F`，或选择「编辑 → 在文件夹中搜索」，打开侧栏的「搜索」页。输入关键词后会在停止输入约 300ms 后搜索，也可按 `Enter` 或「搜索」立即开始。支持中文和其他 Unicode 文本，输入框下方的三个按钮可组合使用，悬停显示说明，按下状态表示启用：

- `Aa`「区分大小写」：关闭时忽略大小写，例如 `plan` 也能找到 `Plan`。
- `ab`「全字匹配」：匹配两侧不能紧邻 Unicode 字母、组合标记、数字或连接标点（如 `_`）。`cat` 不匹配 `scatter`、`cat2` 或 `_cat`；`计划` 可匹配 `计划！`，不会匹配 `新计划`。此选项按字符边界判断，不进行中文分词。
- `.*`「正则表达式」：使用 Qt / PCRE2 语法逐行匹配，例如 `^#{1,6}\s` 查找标题标记、`TODO|FIXME` 查找待办、`note\d+` 查找编号。直接输入表达式，无需 `/…/` 分隔符。关闭时 `.`、`+`、`[` 等字符按字面搜索；全字匹配也保留这些字面字符。

表达式无效时会提示检查表达式；单次匹配超过回溯或深度上限时会提示简化表达式后重搜，已完成行的结果仍可查看。修正输入或切换选项后会自动重新搜索，旧任务不会覆盖新结果。

搜索范围使用文件侧栏当前的工作区。没有工作区时，使用当前文档目录；没有文档时，使用启动目录。范围显示在输入框上方，悬停可看到完整路径。选择「文件 → 打开文件夹」可更换范围，切换工作区会清除旧结果。

结果按文件分组，组名显示相对路径，以区分不同目录的重名文件。每条结果显示 Markdown 源码行号及匹配位置附近的预览；一行多次匹配只列一次。`↓` 从搜索框进入结果，使用方向键选择，`Enter` 或双击打开该源码行并选择首个命中的实际文本。零宽表达式（如 `(?=TODO)`、`^$`）将光标放到命中位置；空行和文件末尾的空行也可匹配。定位会切换到源码视图，`Ctrl+/` 可返回渲染视图。

搜索使用磁盘上已保存的 Markdown，不会自动保存或替换当前编辑。打开结果时沿用保存 / 放弃 / 取消流程；取消保留当前文档、段落源码草稿和撤销记录。搜索页打开期间不会因焦点移入搜索框而自动应用段落草稿，仍可使用草稿自己的「应用」或「取消」。

结果生成后，文件可能已被修改或删除。打开时会校验命中行是否仍然相同；变化时提示重新搜索，避免按旧位置选择无关内容。被删除或无法打开的文件会报错，并保留当前编辑内容。

搜索在后台执行。修改关键词或任一匹配选项会取消旧任务，旧结果不会覆盖新结果；「取消」保留当前轮已找到的部分结果。`Esc` 停止搜索，清空输入会清除结果。切换到其他侧栏页、隐藏侧栏或关闭窗口会取消当前任务；再次打开搜索后可按「搜索」重跑。匹配选项在当前窗口内保留，独立于文档内的查找栏。

范围与上限：

- 只读取 `.md` / `.MD` 文件，按 UTF-8 解码；跳过隐藏条目、`build`、`node_modules` 及符号链接。
- 默认最多显示 200 行匹配，扫描 10,000 个 Markdown 文件或 100,000 个目录项，累计读取 64 MiB。
- 单个文件上限 4 MiB，跳过包含 NUL 字节的二进制内容及无法读取的文件；界面显示跳过数量。
- 达到结果或扫描上限会明确提示缩小关键词或工作区。当前顺序取决于文件系统遍历，不保证先扫描字母顺序最前的文件。
- 输入上限 512 个字符；逐行匹配，`^` / `$` 对应每条源码行，不支持跨行匹配。
- 正则单次匹配设置 PCRE2 `LIMIT_MATCH=100000`、`LIMIT_DEPTH=1000`，防止复杂回溯长期占用后台任务；取消在源码行之间检查。
- 多文件替换、文件名筛选和未保存缓冲区全文索引尚未实现。文档内正则搜索 / 替换仍使用 `Ctrl+F` / `Ctrl+H`；按文件名查找使用 [快速打开](Quick-Open.md)。

`workspace_search` 测试覆盖中文、大小写、Unicode 全字边界、正则变长 / 分支 / 捕获组、UTF-16 偏移、零宽 / 空行、无效与超限表达式恢复、CRLF、长行预览、递归剪枝、扫描上限、取消、连续重搜、分组和键盘操作；窗口回归覆盖工作区范围、草稿保护、实际匹配跨度 / 零宽源码定位、过期 / 删除结果、中英文和浅深主题。功能参考 [Typora 搜索](https://support.typora.io/Search/)。
