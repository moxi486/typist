# 列表与任务清单写作

在渲染视图中，`Tab` / `Shift+Tab` 或「段落 → 缩进 / 取消缩进」调整当前条目的层级。选中多项时一起调整；父项移动时会带上选区之外的子项，保留子项的相对层级、列表类型、完成状态和行内格式。反向选区同样有效。

同一层的第一项不能向右缩进，因为它没有可以归属的前一项。选区包含正文或表格时不执行列表缩进，也不会用制表符覆盖选区。在顶层向左退级会将父项变成正文，其子列表相应提升一级。

「段落 → 有序列表 / 无序列表 / 任务列表」可转换当前项或所选段落，不会把嵌套项拉平。转换成任务列表时，已有任务保留完成状态，新任务初始为未完成；切换为普通列表时移除复选框。粗体、斜体、链接等行内格式保留。缩进、转换类型和批量状态操作均可一步撤销。

同组有序项在编辑区和 PDF 中连续编号，经过子列表后继续原组编号；正文后的新列表从 1 重新开始。DOCX 使用 Word 原生计数器和独立列表编号实例，支持 9 级编号定义，同样保留父列表的续号和独立列表的重新开始。

## 修改任务状态

点击复选框可切换单项状态。「段落 → 任务状态」提供「切换任务状态」「标记为已完成」「标记为未完成」。`Ctrl+Shift+Space` 切换当前项或选区中的任务：选区内全部完成时统一改为未完成，否则统一改为已完成。选区中的普通列表项和正文保留；没有选区时只修改当前任务，不隐式修改子任务。

这些命令用于渲染视图。源码视图可直接修改 `- [ ]` / `- [x]`，状态会在切回渲染视图时恢复。

## 继续、换行与退出

- `Enter` 继续同类列表；新任务为未完成。可从条目中间拆成两项，保留后半段的行内格式。
- 空的嵌套项按 `Enter` 退一级；顶层空项再次 `Enter` 退出列表。
- `Shift+Enter` 在同一项内换行。保存和重新打开、源码切换、HTML / PDF / DOCX 导出均保留换行。DOCX 使用原生 Word 行内换行。
- 任务项中 `Home` 回到复选框后的文字开头，`Shift+Home` 选择任务文字。在文字开头或复选框区域按 `Backspace` 退级或转成正文，避免留下破损的复选框。

当前有序列表仍按 1 开始重新编号；自定义起始编号、列表项拖动排序以及多段落条目的结构化编辑留待后续实现。
