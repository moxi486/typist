# 文件侧栏

按 `Ctrl+Shift+L` 显示或隐藏侧栏，`Ctrl+Shift+O` 打开工作区文件夹。「视图 → 文件树」或 `Ctrl+Shift+3` 使用层级视图；「视图 → 文件列表」将整个工作区的 Markdown 文件放在同一列表，第二行显示所在目录，以区分同名文件。

工作区名称右侧的 `⋯` 按钮提供「文件选项」菜单：

- 文件树 / 文件列表：切换显示方式。
- 文件名：不区分大小写的字母顺序；同名文件使用相对路径确定顺序。
- 自然顺序：文件名中的数字按数值排序，例如 `1-note.md`、`2-note.md`、`10-note.md`。使用固定英文排序规则，使中英文界面及不同系统的数字排序一致。
- 修改时间：按文件的最后修改时间排序，相同时间使用相对路径确定顺序。
- 降序：反转所选排序；修改时间降序会把最近编辑的文件放在前面。
- 文件夹优先：仅在文件树中有效，勾选后每层先显示目录；未勾选时先显示文件。降序不改变这一选择。
- 刷新：重新读取工作区的文件和目录。

默认使用文件树、文件名字母升序、文件优先。显示方式、排序、升降序和文件夹优先选择会保存在应用设置中，关闭并重新打开应用仍然有效。切换设置只改变侧栏显示，保留当前文件选择和文档的内容、光标及撤销记录。

文件树保留各层目录的展开 / 折叠状态，切换到文件列表再切回也会恢复。切换到其他工作区时重置为展开状态。隐藏后重新显示侧栏、或打开工作区内的子目录文件，不会把工作区缩小到当前文件所在目录。

使用 `↑` / `↓` 选择，`Enter` 打开文件；选中目录时 `Enter` 切换展开状态。双击文件也能打开，沿用现有的保存 / 放弃 / 取消导航流程。右键菜单适用于两种视图，操作对象在菜单打开时确定：

- 新建 Markdown 文件 / 新建文件夹：在所选目录内创建；选中文件时使用其父目录，空白处使用工作区根目录。新建文件夹只刷新侧栏，不打开新文档。文件树中选中新目录并展开其父级；文件列表不显示空目录，可切回文件树查看。
- 创建副本：逐字节复制磁盘上已保存的 Markdown 到原目录，保留编码、换行及相对图片 / 链接路径。`note.md` 生成 `note-copy.md`，存在重名时依次尝试 `note-copy-2.md` 等，最多 10,000 个候选，不覆盖已有文件。副本不包含当前未保存的编辑；需要复制这些编辑时先保存原文件。
- 复制文件路径：复制系统格式的绝对路径；复制相对路径：复制相对于工作区的路径，使用 `/` 分隔，工作区根目录为 `.`。两项也适用于目录。
- 打开所在文件夹：调用系统文件管理器打开文件的父目录；选中目录或空白处时打开该目录本身，不保证在管理器中高亮文件。
- 重命名 / 删除：继续使用原有文件操作；本批不增加目录重命名、目录删除或文件操作撤销。删除仍是永久删除。

创建副本、新建文件夹和复制路径均保留当前打开文档及撤销记录，不自动打开副本。新建文件与重命名共用单名称校验，拒绝路径分隔符、系统保留字符、`.` / `..` 及 Windows 保留名称；名称两端空白会去掉。创建文件使用不覆盖模式。取消名称窗口不会创建或重命名文件，失败会显示中英文错误提示。

侧栏可显示任意深度的 `.md` / `.MD` 文件及空目录。隐藏条目、`build`、`node_modules` 和符号链接会跳过。可见侧栏监听实际工作区目录，列表视图也能发现深层新增文件；按修改时间排序时还监听文件变化，自动重新排序。刷新会保留仍存在的当前选择，删除的文件会移出侧栏；切换工作区时移除旧监听。

本批侧栏使用原生 Qt 控件同步读取目录；大型目录的后台文件名查找可使用 [快速打开](Quick-Open.md)。目录切换与固定见 [最近文件夹与固定工作区](Folder-Locations.md)。创建时间排序、列表按目录分组、文件拖动移动尚未实现。功能参考 [Typora 文件管理](https://support.typora.io/File-Management/#files-sidebar)。

`file_browser` 测试覆盖逐字节副本、重名递增、不覆盖、名称边界、上下文目标固定、剪贴板路径、系统文件夹 URL 分发、新建文件夹 / 取消，以及递归过滤、排序、展开状态、刷新、文件监听、键盘和菜单；`window_regressions` 另覆盖偏好保存、中英文、浅深主题、创建窗口、工作区保留及未保存文档 / 撤销记录不变。
