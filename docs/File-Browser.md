# 文件侧栏

按 `Ctrl+Shift+L` 显示或隐藏侧栏，`Ctrl+Shift+O` 打开工作区文件夹。「视图 → 文件树」或 `Ctrl+Shift+3` 使用层级视图。「视图 → 文件列表」列出工作区的可见文件，第二行显示所在目录，以区分同名文件。

工作区名称右侧的 `⋯` 按钮提供「文件选项」菜单：

- 文件树 / 文件列表：切换显示方式。
- 文件名：不区分大小写的字母顺序；同名文件使用相对路径确定顺序。
- 自然顺序：文件名中的数字按数值排序，例如 `1-note.md`、`2-note.md`、`10-note.md`。使用固定英文排序规则，使中英文界面及不同系统的数字排序一致。
- 修改时间：按文件的最后修改时间排序，相同时间使用相对路径确定顺序。
- 创建时间：按文件系统提供的创建时间排序；系统未提供时使用修改时间。悬停条目可查看日期，回退时会注明「创建时间不可用，使用修改时间」。日期相同时使用相对路径确定顺序。
- 降序：反转所选排序；修改时间降序会把最近编辑的文件放在前面。
- 文件夹优先：仅在文件树中有效，勾选后每层先显示目录；未勾选时先显示文件。降序不改变这一选择。
- 按文件夹分组：仅在文件列表中有效，按文件的直接父目录建立分组；组内使用当前排序和升降序。切换回文件树时保留这一选择，文件树仍使用独立的「文件夹优先」选项。
- 「显示隐藏文件和文件夹」开启后，文件树和文件列表会纳入点号开头或被系统标为隐藏的 Markdown 文件，以及隐藏目录中的 Markdown 文件。文件树也显示隐藏的空目录。开关默认关闭，重启后保留。 [Typora 1.14 更新说明](https://support.typora.io/What%27s-New-1.14/#config-which-files-to-show-in-sidebar)
- 「显示非 Markdown 文件」开启后，文件树和文件列表也会显示图片、PDF 等工作区文件。双击、按 `Enter` 或选右键菜单的「用默认应用打开」，都交给系统默认应用处理。开关默认关闭，重启后保留，可与隐藏条目开关同时使用。 [Typora 1.14 更新说明](https://support.typora.io/What%27s-New-1.14/#config-which-files-to-show-in-sidebar)
- 刷新：重新读取工作区的文件和目录。

### 自定义文件筛选

在「文件选项 → 文件筛选」里，每行输入一条包含或排除规则。包含规则留空时沿用「显示非 Markdown 文件」开关。填写后，只显示匹配任意一条包含规则的文件。排除规则优先，也可隐藏整个目录及其内容。

- `*.png` 匹配各层目录中的 PNG 文件，`notes/*.md` 匹配 `notes` 的直接子文件。
- `notes/**/*.md` 也匹配 `notes` 下任意深度的 Markdown 文件。
- 排除 `drafts` 会跳过任意层级名为 `drafts` 的文件和目录。排除 `notes/drafts` 只匹配该相对路径。

相对路径使用 `/`，匹配不区分大小写。规则应用于文件树和文件列表，重启后保留。清空两个规则框即可恢复常规显示。隐藏条目仍受「显示隐藏文件和文件夹」开关控制。 [Typora 1.14 更新说明](https://support.typora.io/What%27s-New-1.14/#config-which-files-to-show-in-sidebar)

默认使用文件树、文件名字母升序、文件优先，文件列表分组关闭。显示方式、排序、升降序、文件夹优先和列表分组选择会保存在应用设置中，关闭并重新打开应用仍然有效。旧设置继续有效；缺少分组设置时保持原有的平铺列表。切换设置只改变侧栏显示，保留当前文件选择和文档的内容、光标及撤销记录。

分组列表首先显示「工作区根目录」（仅在根目录有可见文件时），然后按目录相对路径的自然升序排列分组，例如 `folder2` 在 `folder10` 前面。深层目录使用完整相对路径，以区分不同位置的同名目录。直接包含可见文件的目录才会分组。降序只改变组内文件顺序。

点击分组箭头或选中后按 `Enter` 可折叠 / 展开；双击或按 `Enter` 打开文件的行为不变。分组标题的右键菜单提供目录操作（如新建文件夹、复制路径）。当前工作区内，刷新、排序或暂时关闭分组会保留分组折叠状态；文件树的折叠状态单独保存。新分组默认展开，切换工作区后重置；通过快速打开等方式选中文件时会展开其所在分组。

文件树保留各层目录的展开 / 折叠状态，切换到文件列表再切回也会恢复。切换到其他工作区时重置为展开状态。隐藏后重新显示侧栏、或打开工作区内的子目录文件，不会把工作区缩小到当前文件所在目录。

通过目录别名打开同一文件时，侧栏也能定位该条目，例如 macOS 的 `/var/...` 与 `/private/var/...`。匹配使用实际文件位置，保留侧栏当前显示的工作区路径。

使用 `↑` / `↓` 选择，`Enter` 打开文件；选中目录时 `Enter` 切换展开状态。双击或按 `Enter` 打开 Markdown 时沿用保存 / 放弃 / 取消流程。打开其他文件会保留 Typist 中的文档与未保存编辑。这些文件可复制路径和在文件管理器中定位，创建副本、重命名和移到废纸篓仍是 Markdown 操作。

把文件或文件夹从侧栏拖到正文，在松开鼠标的位置插入链接。链接文字使用条目名称。已保存文档优先使用相对于文档所在目录的路径，未保存文档和无法生成相对路径的条目使用 `file:` 链接。源码模式和代码块插入 Markdown 链接文本，正文中的链接可按住 `Ctrl`（macOS 上为 `⌘`）点击打开。可撤销链接插入。

在文件树内，把文件或文件夹拖到目标文件夹，或拖到树的空白处移回工作区根目录。移动在同一工作区、同一文件系统内完成，保留文件名与文件内容。目标同名、拖到原目录或将文件夹拖入自身及其子目录时，磁盘内容保持原样。移动当前文档或其父目录后，可继续编辑并保存到新位置，选区及正文的撤销记录保留。相对链接与图片路径按新位置解析，Markdown 中的路径原文保持原样。 [Typora 文件管理说明](https://support.typora.io/File-Management/#move-file)

从资源管理器、Finder 或其他文件管理器把本地文件或文件夹拖到侧栏，可复制到工作区。拖到文件夹时使用该文件夹，拖到文件时使用它的父目录，拖到空白处时使用工作区根目录。可一次拖入多个条目，原件保留，同名条目会跳过。目录递归复制，遇到符号链接或目录联接点时会跳过该顶层条目并提示。复制后仍在原文档中编辑，显示结果遵循侧栏的文件筛选设置。

在「设置 → 文件拖放」中，可分别设置从外部拖入 Markdown 文件或文件夹时的动作。默认打开文件或切换工作区；打开文件时仍会处理未保存内容。选择「插入链接」后，可拖到正文、源码或段落源码的插入位置。链接使用当前文档目录计算相对路径，无相对路径时使用 `file:` 链接。一次拖入多个条目时，使用其中第一个可用的 Markdown 文件或文件夹。设置会保存，图片拖放继续使用图片导入。 [Typora 1.6 更新说明](https://support.typora.io/What%27s-New-1.6/#files-section-in-preferences-panel)

从 Typist 的文件树或文件列表把文件或文件夹拖到系统文件管理器，可复制到所选目录。文件管理器负责复制及同名处理，工作区保留原件。复制的是磁盘上已保存的版本。 [Typora 文件管理说明](https://support.typora.io/File-Management/#move-file)

在侧栏右键菜单或「文件选项 → 撤销文件操作」中，可撤销当前工作区最近一次移动或重命名。正文的撤销记录与文件操作各自独立。原位置已有同名条目时会提示失败，解决冲突后可重试；文件在磁盘上被替换后，撤销也会失败。切换工作区，或成功新建、创建副本、拖入复制、移到废纸篓后，撤销记录清空。已进废纸篓的条目可从系统废纸篓恢复。 [Typora 文件操作说明](https://support.typora.io/File-Management/#undo-file-operation)

右键菜单适用于两种视图，操作对象在菜单打开时确定。

- 在新窗口打开：把选中的文件或文件夹交给一个独立窗口，当前窗口保留文档和未保存编辑。在空白处使用此命令时打开当前工作区。
- 新建 Markdown 文件 / 新建文件夹：在所选目录内创建；选中文件时使用其父目录，空白处使用工作区根目录。新建文件夹只刷新侧栏，不打开新文档。文件树中选中新目录并展开其父级；文件列表不显示空目录，可切回文件树查看。
- 创建副本：逐字节复制磁盘上已保存的 Markdown 到原目录，保留编码、换行及相对图片 / 链接路径。`note.md` 生成 `note-copy.md`，存在重名时依次尝试 `note-copy-2.md` 等，最多 10,000 个候选，不覆盖已有文件。副本不包含当前未保存的编辑；需要复制这些编辑时先保存原文件。
- 复制文件路径：复制系统格式的绝对路径；复制相对路径：复制相对于工作区的路径，使用 `/` 分隔，工作区根目录为 `.`。两项也适用于目录。
- 在文件管理器中显示：从文件右键菜单打开所在目录并选中文件。Windows 使用资源管理器，macOS 使用 Finder，Linux 使用支持文件选中的文件管理器。系统无法选中文件时打开其所在目录。目录项和侧栏空白处的「打开文件夹」会直接打开对应目录。 [Typora 文件侧栏说明](https://support.typora.io/File-Management/#actions-in-file-sidebar)
- 重命名 / 移到废纸篓：适用于 Markdown 文件。确认后将磁盘文件交给系统回收站或废纸篓；操作失败时会提示错误。可在系统文件管理器中恢复已移走的文件。

将当前打开的文件移到废纸篓后，编辑器会保留内容、选区和撤销记录，并将它作为未保存文档继续编辑。使用「另存为」选择新路径；同一目录的相对图片会随保存迁移。将其他文件移到废纸篓时可继续编辑当前文档。

「设置 → 默认 Markdown 扩展名」提供 `.md`（初始值）、`.markdown`、`.mdown` 和 `.mkd`。首次保存、另存为或侧栏新建时可用此设置补齐扩展名。手动填写支持的扩展名时会保留输入。侧栏重命名时省略扩展名会沿用文件原有的扩展名，副本也沿用原文件的扩展名。 [Typora 1.6 更新说明](https://support.typora.io/What%27s-New-1.6/#files-section-in-preferences-panel)

创建副本、新建文件夹和复制路径均保留当前打开文档及撤销记录，不自动打开副本。新建文件与重命名共用单名称校验，拒绝路径分隔符、系统保留字符、`.` / `..` 及 Windows 保留名称；名称两端空白会去掉。创建文件使用不覆盖模式。取消名称窗口不会创建或重命名文件，失败会显示中英文错误提示。

侧栏可显示任意深度的 Markdown 文件（支持上述四种扩展名，大小写均可）及空目录。`.git`、`build`、`node_modules` 和符号链接会跳过。可见侧栏监听已纳入的工作区目录，平铺或分组列表都能发现深层新增文件；按修改 / 创建时间排序时还监听文件变化，更新排序。切换到日期排序前会重新读取元数据，手动刷新也会更新日期；创建时间取决于文件系统，复制或原子保存可能改变它。刷新会保留仍存在的当前选择，删除的文件会移出侧栏，空的分组会移除；切换工作区时移除旧监听。

本批侧栏使用原生 Qt 控件同步读取目录；大型目录的后台文件名查找可使用 [快速打开](Quick-Open.md)。目录切换与固定见 [最近文件夹与固定工作区](Folder-Locations.md)。功能参考 [Typora 文件管理](https://support.typora.io/File-Management/#sort-files)。

`file_browser` 测试覆盖分组自然顺序 / 组内排序、深层重名目录、独立折叠 / 重建、创建时间与元数据刷新、偏好默认与恢复、平铺 / 分组文件监听、日期排序下的原子保存，以及副本、名称校验、路径菜单、目录别名和既有文件树回归；`window_regressions` 另覆盖偏好保存、中英文、浅深主题、分组标题翻译、创建窗口、工作区保留及未保存文档 / 撤销记录不变。

## 启动时打开什么

在「设置 → 启动时」选择打开空白文档（默认）、恢复上次的文件夹、恢复上次的文件和文件夹，或打开指定文件夹。指定目录在选择完成后生效，下次启动时打开。

恢复以最近一次成功关闭的窗口为准。工作区和已保存文档分别恢复，即使文档位于工作区之外。窗口没有工作区时，使用已保存文档所在的目录。路径已被移走或删除时，仍可恢复另一项。异常退出后若留有草稿，可通过「文件 → 恢复草稿」找回。

通过系统文件关联或命令行传入现有文件或目录时，优先打开该路径。`typist --new` 打开空白文档，「文件 → 新建窗口」也采用这一行为。`typist --reopen-file` 恢复上次关闭的文档和工作区。 [Typora 启动选项](https://support.typora.io/Launch-Options/) [Typora 启动参数](https://support.typora.io/Launch-Arguments/)

## 重开文件与清除记录

「设置 → 记录最近文件和文件夹」默认开启。关闭后，打开、保存或关闭文档以及切换工作区都不会写入新的最近记录、关闭历史或启动恢复路径。已有记录仍可访问，固定文件夹仍可增删。「清除最近记录」随时可用。重新开启后，后续操作恢复记录。 [Typora 1.7 更新说明](https://support.typora.io/What%27s-New-1.7/#pinned-and-recent-folder)

从「文件 → 重新打开已关闭的文件」按关闭时间从近到远重开文档，最多记住 8 个。新建文档、成功切换到其他文件或关闭窗口时会记录原来的已保存文件。重开在当前窗口进行，遇到未保存编辑时沿用保存、放弃或取消流程。取消后可以再次重开同一项。已删除或移走的文件会跳过。

「文件 → 最近文件 → 清除最近记录」会清空最近文件、最近文件夹、已关闭文件列表和用于启动恢复的文件及目录记录。固定文件夹和指定启动文件夹仍可使用。后续打开或关闭文档时会重新记录。 [Typora 最近文件与文件夹](https://support.typora.io/File-Management/#recent-files--folders)

## Markdown 换行符

在「设置 → 默认换行符」为新文档选择 Unix (LF) 或 Windows (CRLF)，默认 LF。已有文档保存、另存为和自动保存时沿用原换行风格。混用换行符的文件按首个换行符统一，只有旧式 CR 换行的文件保存为 LF。没有换行符时使用当前默认值。 [Typora 换行符说明](https://support.typora.io/Typora-on-Windows/#line-ending)
