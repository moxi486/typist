# 最近文件夹与固定工作区

点击侧栏工作区名称旁的文件夹按钮，或选择「文件 → 最近与固定文件夹」，可以查看最近打开的目录、固定常用目录并切换工作区。固定目录排在最近目录之前，同一个目录只显示一次；重名目录通过完整路径区分，过长路径会缩略，悬停可查看原路径。

打开文件夹，或成功打开一个 Markdown 文件时，会记录其当前工作区；没有显式工作区时记录文件的父目录。最近位置按使用时间保留 12 个，固定目录单独保存，最多 16 个，不会因最近记录达到上限而丢失。

在菜单中选择「固定当前文件夹」或「取消固定当前文件夹」修改固定状态。「从最近记录中移除当前文件夹」只移除最近记录；「清空最近文件夹（保留固定）」保留固定目录。以上操作只更改应用设置，不移动或删除磁盘上的文件夹。

目录使用绝对规范路径保存，同一个目录的 `.` / `..` 或符号链接别名会合并；Windows 下也会忽略路径大小写差异。不存在的目录不会显示；每次更新记录时会清理无效路径。目录在菜单打开后被删除时，选择它会提示无法打开，并保留当前文档和工作区。

最近位置和固定状态保存在 Typist 的用户设置中，关闭应用后仍然保留。应用不会在启动时自动打开这些目录，也不会同步到其他设备。

## 用 Ctrl+P 打开文件夹

[快速打开](Quick-Open.md) 同时包含最近文件、最近文件夹和固定文件夹。空关键词时固定文件夹在前；输入关键词后，文件与文件夹按名称 / 路径的匹配程度排序。文件夹使用目录图标，并标注「固定文件夹」或「最近文件夹」。

`Enter` 或双击文件夹会切换工作区，关闭快速打开窗口。再次按 `Ctrl+P` 会在新工作区中查找文件；本批只列出已记录的文件夹，不索引所有子目录作为文件夹候选。

## 切换时保留文档

切换工作区只改变文件侧栏和工作区搜索范围。当前文档、保存路径、图片解析目录、源码 / 渲染模式、光标、撤销记录和段落源码草稿均保留；不会因为选择另一个目录而自动保存、关闭或重新加载当前文档。当前文件可以位于新工作区之外。

切换会回到「文件」页并取消旧的工作区搜索。之后如果打开另一份文件，仍沿用原有的保存 / 放弃 / 取消导航流程。界面支持中英文及浅深主题。

`folder_locations` 测试覆盖路径去重、保存与恢复、最近记录上限、固定目录上限、清空与移除、无效位置、菜单及快速打开；窗口回归覆盖跨工作区文档 / 草稿保留、从搜索页通过 Ctrl+P 切换、焦点恢复、中英文与主题。功能参考 [Typora 文件管理](https://support.typora.io/File-Management/#pin-folders)。
