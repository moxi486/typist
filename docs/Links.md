# 链接编辑与导航

渲染视图中，普通单击保留文字编辑行为；`Ctrl+单击`（macOS 使用 `Cmd+单击`）打开链接。拖动选择文字不会触发跳转。悬停可查看地址和操作提示。

- `#标题-id` 跳转到当前文档标题。
- `notes/detail.md#next-step` 按当前文档所在目录解析，打开 Markdown 文件并定位标题。支持中文、空格、百分号编码、本地绝对路径与 `file:` URL。没有扩展名时依次查找 `.md`、`.markdown`、`.mdown`、`.mkd`。
- `http:` / `https:` 和 `mailto:` 交给系统默认应用打开；其他本地文件或目录交给关联应用。

切换 Markdown 文件沿用保存保护：未保存修改可以保存、放弃或取消，取消后保留当前正文、光标与撤销历史。缺失文件、未知标题或不支持的 URL 协议会在状态栏提示，不会创建文件。未命名文档没有文件夹基准，需先保存才能解析相对文件路径。

## 编辑与复制

光标放入链接后按 `Ctrl+K`，可修改显示文字和地址；选中文字后也可创建链接。标题下拉框提供当前文档的标题，浏览按钮选择本地文件并生成相对地址。只修改地址时保留链接内的粗体、斜体等行内格式；修改显示文字时以新文字替换原标签。取消对话框不修改文档。

链接右键菜单提供打开、编辑、复制地址和移除链接。移除链接保留文字及其他行内格式。标题右键菜单可复制 `#标题-id`，重复标题自动加数字后缀。链接编辑与移除均为一次可撤销操作；导航、复制和查看地址不增加撤销记录。完整源码视图中直接编辑 Markdown 链接。

## 标题 ID 与导出

标题 ID 忽略首尾空白，使用小写文字，保留字母、数字、`-` 和 `_`，将空白变成 `-`，移除其他标点；空结果使用 `section`。重复 ID 依次追加 `-1`、`-2`，并避开已有 ID。例如 `Hello, World!` → `hello-world`，`中文 标题` → `中文-标题`。

HTML 导出为标题加入这些 ID，并同步自动目录的链接。DOCX 将已知的当前文档标题链接写为 Word 内部书签链接；外部网址和跨文件链接仍使用外部超链接。引用块内的标题目前沿用原有源码显示方式，不提供正文标题选择或应用内跳转；HTML 自动目录仍可访问其导出标题。

PDF 中保留链接文字和样式，交互链接注释尚未实现。自定义 HTML 锚点、缺失文件创建引导和自动修复重命名后的链接留待后续。
