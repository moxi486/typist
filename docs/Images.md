# 图片与本地资源

可直接粘贴剪贴板截图，或把本地图片拖到编辑区。格式菜单中的「图片」也使用相同导入流程。一次可插入最多 20 个图片文件。每次插入可一步撤销；撤销不删除磁盘图片，以保留重做、草稿和其他文档引用。

默认把导入的图片复制到 Markdown 文件旁的 `<文件名>.assets` 目录，Markdown 使用相对路径。PNG、JPEG、GIF 等原文件按字节复制；截图保存为保留透明度的 PNG。资源以内容摘要命名，重复插入复用文件，已有不同内容的同名文件不会被覆盖。复制后的图片不依赖原始文件继续存在。编辑器的预览限制在 640×480 内，资源文件保留原图。

未命名文档的截图保存在应用数据目录的 `images` 子目录，不使用会自动清理的临时目录。保存到 Markdown 文件时，图片会复制到该文档的资源目录，并更新链接。已有文档另存到其他位置时，同样复制相对图片、改写真实图片链接；代码示例中的相同文字不会被修改。原资源保留。

「设置 → 将图片复制到文档资源目录」可关闭本地文件的复制，改为引用源文件；剪贴板截图仍需要保存。关闭复制后要保持源文件可访问。图片地址中的空格、中文、括号和 `#` 采用 URL 编码，避免 Markdown 路径解析歧义。不会从远程地址自动下载图片。

完整源码视图和段落 Markdown 编辑框粘贴图片时插入 Markdown 链接；代码块中的文字粘贴仍按原文处理，纯截图不会插进代码块。拖入 `.md` 文件打开文档，不把文件路径插入正文。

HTML 导出会把可读取的本地图片内嵌为 data URL，HTML 文件可独立移动；PDF / DOCX 继续内嵌图片。缺失或不支持的图片保留其 Markdown 信息，不会移除正文。单个导入文件上限为 64 MiB，截图上限为 3200 万像素。

另存为支持直接书写的图片链接。使用 `![alt][reference]` 定义的相对图片，在跨目录保存前需改为 `![alt](path)`；应用会提示并保留当前文档，避免静默生成失效链接。资源目录目前不自动清理；移除不用的图片前，请自行确认其他文档与恢复草稿没有引用。
